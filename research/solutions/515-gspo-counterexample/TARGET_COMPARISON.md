# Comparison with AIM 515

Target: [Consistency of the Greedy Sparsest Poset algorithm](https://github.com/MColbrook/AIM/blob/c9929805cece044705abaaebe1cebddac1ba11a6/problems/515-greedy-sparsest-poset-consistency.md), revision `c9929805cece044705abaaebe1cebddac1ba11a6`.

The universal assertion is refuted by one admissible distribution and one starting vertex. Theorem 1 of the [manuscript](paper/counterexample.pdf) states that counterexample. No quantifier is replaced by a generic-coefficient, finite-depth or fully faithful hypothesis.

| Original requirement | Admissible object and manuscript location |
| --- | --- |
| Finite observed vertex set | `V={1,2,3,4,5,6}`; Section 2. |
| A distribution Markov to a DMAG `G*` | The Gaussian structural equation model (2); invertible noise transform and covariance (5); Section 3 and Tables 1–2 prove the Markov property and maximality of the six-edge DAG. |
| Full restricted-faithfulness condition, for every conditioning subset | Section 3 and Tables 1–2 cover all 240 pair/conditioning queries. The sole extra independence is the marginal pair `(1,6)`, which is not adjacent, does not share a neighbor, and cannot be the endpoints of a discriminating path. |
| The exact map, including both `A` operations and maximal ancestral closure | Equation (1) defines it. Equation (6) and Table 3 establish the fixed points; maximality then makes closure the identity. The symmetry in Section 3 supplies the third graph. |
| A starting graph in the original image | The explicit poset generated by `1<2<3` and `4<5` gives `G_pi0=H0`; Theorem 1, Section 3 and equation (7). |
| Only legitimate single mark changes followed by `G_po(H')` | Lemma 2 quotes the local Zhang–Spirtes criterion. Section 4 covers all 38 potential single changes in the three graphs, including both orientations of each bidirected edge. Reconstruction fixes the four legitimate successors. |
| A finite nonincreasing path to the global edge minimum | Section 4 proves the reachable set is exactly `H0 <-> H1 <-> H2`, all with eight edges. No path leaves it, even without the nonincrease restriction. |
| The global minimum over all posets | Section 3 proves every image contains the six true adjacencies and shows `G_po(G*)=G*`, so the global minimum is exactly six. No exhaustive enumeration of all posets is needed for this lower bound. |
| Connection to the true equivalence class | The paragraph after the proof observes that `G*` separates `(2,6)` given `{1,3}`, while every component graph contains their edge. |

The six-variable distribution is credited to Bernstein, Saeed, Squires and Uhler (2020), Figure 1. The additional argument establishes the closed search component for that input. A bounded prior-source check did not verify an existing proof or counterexample covering this complete search assertion; that check is not a novelty certificate.

The result concerns the exact restricted-faithfulness assertion in the pinned problem. It makes no claim for full faithfulness, generic coefficients, changed moves, finite-sample testing, or computational complexity. This package supplies a complete counterexample claim for independent review; it does not assert upstream acceptance.
