# Manuscript

main.tex is a standalone article with an inline bibliography. main.pdf is its rendered 12-page manuscript. The author is Kaiwen Jin and the contact is yui.ui.siki@gmail.com. Section 2 states the complete fixed-scheme theorem; Sections 3 and 4 prove the quadrature bounds and terminal convergence estimate.

Build from the package root using the root README command. No additional local files or data are required.
